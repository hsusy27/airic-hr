# 人工智慧暨機器人創新中心 (AIRIC) - 新聘人員進用資格審核系統

本系統為一套專為醫療院所與創新中心設計的輕量化 Web 應用程式，旨在協助行政與人資團隊自動化「新聘人員進用」的資格比對流程。透過串接 Google Gemini API，系統能精準理解各職缺的門檻規範，嚴格把關應徵者資歷，並一鍵生成對應的官方簽呈或退補件通知，大幅降低行政作業的時間成本。

## 核心功能說明

1. **AI 智慧條件把關**：
   * 內建多種職位（如：演算法工程師、專案經理等）的進用規範範本，亦支援自訂條款。
   * 透過 Gemini AI 語意分析，嚴格交叉比對履歷與規範。若缺少關鍵要求（如：推薦信、特定年資、特定發表數量），系統將自動判定不符並列出具體缺漏原因。

2. **自動化公文生成**：
   * 審核通過：自動草擬標準院內公文簽呈（包含主旨、說明、擬辦與經費來源），可直接複製使用。
   * 審核未過：自動生成退件 / 補件通知函，明確告知應徵者需補齊的資料項目。

3. **一鍵個資去識別化與檔案下載**：
   * 自動掃描並遮蔽面試紀錄表或履歷中的敏感個人資料（包含：身分證字號、Email、手機/市話、出生年月日）。
   * 提供獨立編輯方框供人工微調，並支援將去識別化後的乾淨文本直接下載匯出為 `.txt` 檔案，方便歸檔與跨部門傳閱。

4. **多格式檔案解析**：
   * 支援檔案拖曳上傳（Drag & Drop）。
   * 整合 pdf.js，可直接於前端讀取並解析 PDF 履歷或佐證資料內文。

## 資料檔案去向與個資安全保護 (Data Privacy & Security)

為了符合醫療院所對個資保護（PII）與資安嚴格規範，本系統在架構設計上採取極高標準的隱私防護機制：

1. **零伺服器留存（純前端運作）**：
   * 所有上傳的履歷、面試紀錄表、PDF 或圖檔，完全僅在您的電腦瀏覽器本機記憶體中進行解析。
   * 本系統無任何後端資料庫，絕不會將您上傳的檔案存檔、備份或傳送至任何第三方伺服器。

2. **API Key 本機安全加密**：
   * 您的 Google Gemini API Key 僅會以加密方式儲存在您個人電腦瀏覽器的 LocalStorage 中。
   * 金鑰不會上傳至任何雲端或系統紀錄中，您可以隨時點擊右上角按鈕一鍵清除。

3. **AI 運算資安防護**：
   * 傳送至 Gemini API 的資料僅限於您於介面上看到的文字內容，用於當下的資格比對與公文生成。
   * 建議於送出 AI 比對前，先點擊「快速去識別化」按鈕遮蔽敏感個資（身分證字號、聯絡電話、生日、Email），落實最小化資料暴露原則。

## 技術架構

* **前端介面**：HTML5, JavaScript (Vanilla), Tailwind CSS (透過 CDN)
* **檔案解析**：PDF.js
* **AI 引擎**：Google Gemini API (預設相容 gemini-3.6-flash 模型)
* **部署方式**：純靜態網頁架構，完全無伺服器 (Serverless)，可直接託管於 GitHub Pages 或任何靜態網頁伺服器。

## 快速開始與使用步驟

### 1. 本機執行與部署
本系統為純靜態檔案，無須安裝 Node.js 或任何後端資料庫。
* 將專案下載到電腦後，直接使用瀏覽器開啟 `index.html` 即可執行。
* 若要上線給同事使用，將檔案推播至 GitHub 倉庫並啟用 GitHub Pages 即可。

### 2. API 金鑰設定
為了啟動核心的 AI 審查機制，請準備一組 Google Gemini API Key：
1. 點擊系統右上角的「Gemini API : 本機模式」按鈕。
2. 貼上您的 API Key 並點擊儲存（金鑰將安全地加密儲存於您當前瀏覽器的 LocalStorage 中，不會外洩）。
3. 狀態燈號轉為綠色即代表連線成功。

## 程式小白自主修改指南 (How to Edit)

如果你未來想要調整系統內容，不需要懂複雜的程式碼，打開 `index.html` 搜尋以下位置即可直接修改：

1. **想修改或新增預設職缺條件**：
   * 打開 `index.html`，按 `Ctrl + F` 搜尋 `const templates = {`。
   * 你會看到每個職缺對應的中文規範文字，直接在那裡修改或增加職缺文字即可。

2. **想修改自動去識別化要遮蔽的關鍵字**：
   * 打開 `index.html`，搜尋 `function anonymizeInputText()`。
   * 裡面的 `replace` 區域就是負責替換文字的地方，例如想把替換後的文字從 `[身分證字號已遮蔽]` 改成 `[遮蔽]`，直接改引號內的文字即可。

3. **想修改抬頭名稱或 Logo**：
   * 打開 `index.html`，搜尋 `<header>` 區塊。
   * 修改裡面的 `h1` 文字（系統標題）或圖片路徑即可。
